# 🌱 KrishiMitra AI

> **An AI-powered agricultural assistant designed to help farmers make smarter decisions. 🌾🤖**

KrishiMitra AI is a modern agricultural assistance platform that brings together AI-powered support, crop recommendations, agricultural data, plant disease assistance, and voice interaction into a single user-friendly experience.

The project focuses on making useful agricultural technology more accessible through a simple and interactive web interface.

---

## ✨ Features

### 🌾 Crop Recommendation

Helps users explore suitable crop recommendations using agricultural and crop-yield data.

### 📊 Agricultural Data

The project includes agricultural datasets and crop-yield information to support data-driven features.

### 🦠 Plant Disease Assistance

Users can provide plant or crop images to receive assistance related to potential crop diseases.

### 🎙️ Voice Interaction

Voice functionality allows users to interact with the platform through speech, making the experience more accessible and convenient.

### 📍 Location & Geographic Data

The project includes Indian city and geographic data to support location-related agricultural functionality.

### 💻 Modern Web Interface

Built with a component-based architecture and responsive styling for a smooth experience across different screen sizes.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Abhishekkuntare/KrishiMitra-AI.git
```

### 2. Open the project

```bash
cd KrishiMitra-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local development URL shown in your terminal to view the application.

## 🌱 Why KrishiMitra AI?

Farmers often need to make decisions involving crops, diseases, yield, and agricultural practices. KrishiMitra AI explores how modern web technologies and AI can bring multiple forms of agricultural assistance together in one accessible platform.
